# AIDMH Website — Hugo + PaperMod

Static website for **aidmh.org**, built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, deployed on [Cloudflare Pages](https://pages.cloudflare.com/).

## 🚀 Quick Start

### Prerequisites

- [Hugo Extended](https://github.com/gohugoio/hugo/releases) (v0.120.0+)
- Git

### Clone & Run Locally

```bash
# Clone this repo
git clone <clone-command-from-card>

# Enter the project
cd aidmh-website

# Initialize the PaperMod theme submodule
git submodule update --init --recursive

# Start the dev server
hugo server -D

# Open http://localhost:1313
```

> If `git submodule update` fails, add the theme manually:
> ```bash
> git submodule add https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
> ```

### Build for Production

```bash
hugo --gc --minify
# Output is in ./public/
```

## ✍️ Adding Content

Create a new post:

```bash
hugo new posts/my-new-post.md
```

Edit the file in `content/posts/my-new-post.md`, then set `draft: false` when ready to publish.

## ☁️ Deploy to Cloudflare Pages

### Method A: Connect Git (Recommended)

1. Push this repo to GitHub
2. Go to [Cloudflare Dashboard → Workers & Pages → Create](https://dash.cloudflare.com/d736fa779a36e96f09e250fa1c3129ec/workers-and-pages/create)
3. Choose **Connect Git** → authorize GitHub → select the repo
4. Set the build configuration:
   - **Framework preset**: Hugo
   - **Build command**: `hugo --gc --minify`
   - **Build output directory**: `public`
   - **Environment variables**:
     - `HUGO_VERSION` = `0.140.0` (or latest stable)
5. Deploy — builds run automatically on every push

### Method B: Direct Upload

```bash
hugo --gc --minify
# Then upload the ./public/ directory via the dashboard
```

## 🌐 Custom Domain Setup

After deploying:

1. **Register `aidmh.org`** at [Cloudflare Registrar](https://dash.cloudflare.com/d736fa779a36e96f09e250fa1c3129ec/registrar/register)
2. **Add custom domain** in the Pages project → **Domains** tab:
   - Add `aidmh.org` (apex)
   - Add `www.aidmh.org`
3. **Configure www → apex redirect**:
   - Add a `_redirects` file or use Cloudflare Redirect Rules
   - `www.aidmh.org` → `https://aidmh.org` (301)
4. **SSL certificate** — Cloudflare auto-issues Universal SSL; verify at [SSL/TLS settings](https://dash.cloudflare.com/d736fa779a36e96f09e250fa1c3129ec/aidmh.org/ssl-tls)
   - Set encryption mode to **Full (Strict)**

## 🎨 Customization

### Change site title / description
Edit `hugo.toml` → `[params]` and `[params.homeInfoParams]`.

### Change colors
PaperMod uses CSS variables. Override in `layouts/partials/extend_head.html`:

```html
<style>
  :root {
    --primary: #1a1a2e;
    --secondary: #16213e;
    --accent: #0f3460;
  }
</style>
```

### Add social links
Edit `hugo.toml` → `[[params.socialIcons]]`.
